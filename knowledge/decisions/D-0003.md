# D-0003 — AGPL-3.0-or-later on the protocol itself, not LGPL

**Decision**: The protocol — the interface every gun mod would compile against
— is AGPL-3.0-or-later, the same as the consumer and the bridges. LGPL for the
interface was proposed and rejected.

**Why**: The author's stated requirement: nobody takes this code, mod or
protocol, and publishes something closed from it — "if you use my code in any
way, shape or form, you have to publish whatever you make from it." LGPL on
the interface would have let a closed gun mod implement `RangedWeapon` and
ship all-rights-reserved. AGPL means a gun mod that implements the Java
interface publishes its source. A gun mod that will not accept that is not
locked out: it stays compatible at the datapack tier (D-0002), which touches
no code and needs no licence contact — a profile is data, and anyone may write
one for any item.

The original author of Armed Pillagers, nfx, signed off on the relicense of
the imported code.

**Alternatives rejected**: *LGPL on the interface, AGPL on the rest* — the
conventional choice for a plugin API, rejected because it is exactly the loophole
the requirement forbids. *A classpath exception* — same loophole, narrower
wording. *MIT/Apache for adoption* — adoption by closed mods is not a goal.

**Follow-ups**: None. Every mod the author writes carries the same licence.
